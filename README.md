# týndur-Paketarchiv

Hier findest du die historischen Pakete von **lpt.tyndur.org**, erstellt mit den [lbuilds](https://github.com/lowlevel-eu/lbuilds) für das Community-Betriebssystem [týndur](https://github.com/lowlevel-eu/tyndur).

Die Paketdateien und Paketlisten bleiben mit ihrer ursprünglichen Verzeichnisstruktur erhalten und werden unter **https://lowlevel-eu.github.io/lpt/** bereitgestellt, beispielsweise in `0.2.2/` und `current/`.

Der historische LPT-Client unterstützt nur HTTP. Für den Zugriff auf das HTTPS-Archiv ist daher ein HTTP-Proxy oder eine Anpassung des Clients nötig.
